# 3. Ontologies

Date: 2026-06-03

## Status

Accepted

## Context

Various elements in LegalDocML require ontology values.

## Decision

We document ontology values in the [Ontologies.md](https://github.com/digitalservicebund/ris-xml-schema/blob/main/Ontologies.md) file.
We only use ontologies if our data quality is high enough to ensure that ontology values are actually representing an
ontology.
